# You are making one episode of "Lumi's Magical Adventures"

A children's YouTube Shorts series on the channel "Little Moon Story World". It is built entirely in code with Remotion (React/SVG) and synthesized audio. Nobody is watching this session or can answer questions: make every decision yourself. The app that started you renders the final video and checks it, so do not try to render the whole episode.

Your working directory is `video-demo/`. The user message gives the episode id (written `epNN` below), its composition id (`EpNN`, for example `Ep04`), and what to make.

## The rules that make it this series

- 1080x1920, 30 fps, 40 to 50 seconds (45 is the usual length). 45 s is 1350 frames, 50 s is 1500.
- No logo or title intro. The first frame is already the most exciting image of the opening: something bursting, flying or glowing, with a sound on frame 0, and motion that is obvious within the first second.
- Ages 3 to 7: warm, gentle, never scary. One clear idea of kindness, courage or curiosity. Short sentences a small child understands, 12 lines or fewer, and under 12 words per line.
- A curiosity ending: a new mystery appears, unresolved, then the end card "To Be Continued... ✨" and "Little Moon Story World 🌙" (`<EndCard>`). Leave the card up for at least 1.5 s.
- Lumi and Bobo must look identical in every episode. Import them, never redraw or restyle them. The little mint creature rides on Bobo's head (`BoboRider`).
- 5 or 6 scenes, each with a purpose, and the camera moving in every shot. Spoken lines in the same scene should feel like a conversation, with gaps under about 1.5 s.
- Real visual variety: use at least one tight close-up of a face, one wide establishing shot and one shot from a different place or angle. Never hold the same framing of the same characters for more than about 8 seconds; cut in closer on whoever is speaking or reacting, or move the characters.

## Files you create

Only these. The app rejects changes to anything else and undoes them.

| File | What it is |
| --- | --- |
| `audio-src/epNN/lines.json` | The script: `[{"id":"l1","speaker":"lumi","text":"...","speed":0.9}]` |
| `scripts/epNN_audio.py` | The soundtrack, using `audio_kit` |
| `src/epNN/Episode.tsx` | The animation. Add `src/epNN/props.tsx` for new props and characters |
| `src/epNN/episode.json` | Written last, see below |
| `src/Root.tsx` | Add one import and one `<Composition>` line. Change nothing else in it |

`public/epNN/audio.wav` and `src/epNN/timeline.json` are generated by the audio step.

## Tools

Bash is limited to these commands. Run them from the working directory, exactly in this form:

- `node tools/studio.mjs voices epNN` generates the voices from `lines.json` and prints each line's length.
- `node tools/studio.mjs audio epNN` runs your soundtrack script. It stops with an error if lines overlap or dialogue is too quiet over the music.
- `node tools/studio.mjs typecheck` checks the TypeScript.
- `node tools/studio.mjs stills epNN 1 8 15 22 30 38 43` renders frames at those seconds into one contact sheet and prints its path. Open it with Read and look at it. It takes a minute or two.

Search tools are not available. The files you need are all named in this guide, so use Read.

## How to work, in this order

1. Write the story and `lines.json`. Generate the voices. The printed lengths decide your timing.
2. Write `scripts/epNN_audio.py`, placing each line with `t.line(id, speaker, start)`, and run it. Keep every timed moment (bursts, reveals) as a named constant so it can match the animation.
3. Write `src/epNN/Episode.tsx` and any props. Register the composition. Typecheck.
4. Run `stills`, read the sheet critically, fix what you see, and repeat. Two or three rounds is normal. Stop at three unless something is clearly broken.
5. Write `src/epNN/episode.json` and finish with a two-sentence summary of the story.

Read these before writing code, because they show the standard to match: `src/kit/index.tsx` (always), `src/story/characters.tsx` lines 1 to 33, `series.json`. Read the first 280 lines of `src/ep03/Episode.tsx` for how a scene is built, and read a prop's source before using it.

## What to check on every contact sheet

- Lumi and Bobo are fully in frame, feet on the ground, not cropped by the frame edge, not floating, not overlapped by props.
- Faces and important action sit between y=250 and y=1500. YouTube's buttons and caption cover the bottom and right edge of a Short.
- Each sheet frame should look clearly different from the last and read clearly at phone size. If several in a row show the same staging, change the shots. Characters should be large: zoom in instead of leaving them tiny.
- Nothing shows a bare background, empty sky or the edge of the painted world.
- Text is readable, and the end card is visible at the end and not sitting on top of a face.
- Characters look at whatever they are reacting to, and whoever is speaking has a moving mouth.

## Drawing and animation

```tsx
import timeline from "./timeline.json";
import { AbsoluteFill, useCurrentFrame } from "remotion";
import { blinkAt, Lumi } from "../story/characters";
import { Woods } from "../ep02/props";
import { BoboRider, EASE, EndCard, EpisodeFrame, ip, makeMouthAt, SparkBurst, Stage } from "../kit";

const mouthAt = makeMouthAt(timeline);
const CUTS = [0, 180, 390, 630, 930, 1170, 1350]; // scene boundaries in frames; the last is the total

const Scene1: React.FC = () => {
  const f = useCurrentFrame();       // frame within this scene
  const g = f + CUTS[0];             // frame within the episode: use for lip sync, blinking, twinkling
  const cam = { cx: 1120, cy: ip(f, [0, 90], [1202, 1190], EASE), z: ip(f, [0, 90], [1.12, 1.17], EASE) };
  return (
    <Stage cam={cam}>
      <Woods g={g} />
      <BoboRider g={g} x={1330} y={1776} scale={0.78} look={{ x: -0.35, y: -1 }} expr="excited" blink={blinkAt(g, 3)} />
      <Lumi x={930} y={1790} scale={0.86} look={{ x: 0.45, y: -1 }} expr="happy" mouth={mouthAt("lumi", g)} blink={blinkAt(g, 1)} />
      <SparkBurst f={f} at={0} x={1120} y={900} reach={520} count={30} size={22} rainbow />
    </Stage>
  );
};

export const Episode: React.FC = () => <EpisodeFrame audio="epNN/audio.wav" cuts={CUTS} scenes={[Scene1 /* ... */]} />;
```

- Cameras: the frame shows 1080/z world units across and 1920/z down, centered on (cx, cy). In `Woods` the ground runs near y=1540 to y=1900 and the painted world spans x=-1000 to x=3400. Characters at y≈1780 with cam cy≈1200 and z≈1.1 stand in a good spot.
- Characters face forward with feet at (x, y); Lumi is about 440 units tall and Bobo about 400 at scale 1. Arm angles rotate an arm hanging down: `armL` positive raises it, `armR` negative raises it. `walk={f * 0.4}` walks in place, so also move x. `walk={null}` stands. Expressions: `neutral`, `happy`, `surprised`, `excited`, `effort`.
- There is no knee bend. To kneel, lower the character behind a foreground bed of flowers (`FrontBed` in `src/ep03/props.tsx`).
- Reuse before drawing new scenery. `src/story/scenery.tsx`: Sky, StarField, Moon, Fireflies, Tree, Mushroom, BushBack, BushFront, Flower, Cottage, Sparkle. `src/ep02/props.tsx`: Woods, GiantTree, LittleDoor, TinySprite, GoldenKey, MagicMap, CurlyPlant, LeafFall, TinyWorldBack, TinyWorldFloor. `src/ep03/props.tsx`: RainbowWorld, RainbowTree, DriftLights, Butterfly, MagicFlower, FrontBed, Ladybug, GiftOrb, GoldenClue, RAINBOW, mix.
- New characters go in `src/epNN/props.tsx`, in the same soft, rounded, glowing style with big eyes, and take `mouth`, `blink` and `look` props if they speak.
- Everything must depend only on the frame. Never use `Math.random` or `Date`; use `random(seed)` from remotion. Keep positions and timings as named constants.
- `mouthAt("speaker", g)` works for any speaker in `lines.json`.

## 3D worlds (from Episode 5)

Scenes can have a real 3D world (Three.js inside Remotion) with the series' 2D characters drawn on top. Use it when a place should have depth, such as a castle, sky islands, a cave or the sea. Plain 2D scenes are still fine. If you use 3D, first read `src/ep05/world.tsx` and the first 120 lines of `src/ep05/Episode.tsx`, which show the whole pattern.

- `src/kit3d/World.tsx`: `World3D` is the 3D layer, with glow, tone mapping and shadows. Give it `cam={{ pos, target, fov }}` in world units. Also `project` and `rng(seed)`.
- `src/kit3d/overlay.tsx`: `camAt(f, [[frame, cam], ...])` moves the camera; two keys one frame apart make a cut. `place(cam, [x, y, z], size)` gives the screen `x`, `y` and `scale` for a character whose feet are at that world point, so characters stay on the 3D ground as the camera moves. `screen(cam, p)` pins 2D effects to 3D objects. `CharLayer` is the 2D layer over the 3D one.
- Sizes: Lumi is about 1.3 world units tall at size 1. A medium shot of three characters is the camera 7 to 9 units away with `fov` 42 to 46; a close-up is about 4 to 5.5 units away.
- `src/kit3d/sky.tsx`: SkyDome, Stars, Moon, Halo, CloudSea, FloatingIsland. `src/kit3d/castle.tsx`: MoonCastle, Bridge, Crescent. `src/kit3d/magic.tsx`: MoonPortal, MoonCrystal, MagicBubble, MoonFlower, GlowGarden, SparkleBurst3D, Motes, LightRing, OceanHologram. `src/ep05/world.tsx`: MoonKingdom and Meadow, ready-made places.
- Build a new place in `src/epNN/world.tsx` from these pieces, and put new 3D props there too.
- The characters are always 2D and always drawn over the 3D layer, so never let a 3D object pass in front of them, and stand them on visible 3D ground.
- Every 3D value must come from the frame: pass `t = g / 30` into components, and never use clocks or `Math.random`.
- On contact sheets, also check for 3D props right in front of the camera filling the frame, and characters standing in empty air.

## Voices

`lines.json` speakers with a fixed voice and pitch: `lumi`, `bobo`, `narrator`, `butterfly`, `draco`, `moonia`. Speeds near 0.85 to 0.95 sound best. A new character needs `"voice"` on each of its lines, chosen from `af_nicole`, `af_sarah`, `af_nova`, `am_adam`, `am_michael`, `bf_emma`, `bm_george`, and a pitch: `t.line("x1", "owl", 12.0, pitch=0.95)`. Write words for the ear, since numbers and unusual names are read literally.

## Soundtrack

```python
from audio_kit import *

t = Soundtrack("epNN", duration=45.0, seed=44)
BURST_T = 31.0
t.line("l1", "lumi", 0.9)
run(t, HOPE, 0.0, 12.0, 0.08)     # music: HOPE, TENDER and JOY progressions, last number is loudness
run(t, TENDER, 12.0, 28.0, 0.06)
run(t, JOY, BURST_T, 40.0, 0.125)
ending_chord(t, 40.0)
forest_air(t)
gliss(t.sfx, 0.0, (72, 76, 79, 84, 88), step=0.06, vol=0.07)   # the sound on frame 0
sparkle(t.sfx, 0.0, 1.4, density=16, vol=0.035)
add(t.sfx, boom(), BURST_T)
add(t.sfx, whoosh(1.5, 0.2), BURST_T)
t.finish()
```

Also in `audio_kit`: `music_box`, `flutter`, `water_drop`, `crickets`, `bird`, `noise_band`, `ping`, `note_hz`. Every important on-screen event should have a matching sound at the same moment. Make new effects in your own script from these if the story needs them.

## `src/epNN/episode.json`

```json

  "title": "The Talking River",

  "synopsis": "One or two sentences on what happens.",
  "ending": "The mystery left open at the end, for the next episode to pick up.",
  "newCharacters": ["Name or description of anything recurring that was introduced"]
}
```

`slug` is 2 or 3 lowercase words joined by hyphens.
