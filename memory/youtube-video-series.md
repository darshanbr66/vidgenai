**Why:** They want to see the episodes as a clean 1, 2, 3 list, not mixed with each other or with other renders, and Lumi and Bobo must look identical in every episode.

**How to apply:**
- Render to `video-demo/out/` as `epNN-<short-title>.mp4`, zero-padded; next number = highest existing `ep` file + 1. Wait for the user's instruction for each episode; don't generate ahead. `demo.mp4` and `darshan-brand.mp4` are not episodes. Never overwrite earlier episodes.
- Keep each episode's code separate: `src/epNN/`, `public/epNN/`, `audio-src/epNN/`, `scripts/epNN_*`, plus a composition in `src/Root.tsx` and a `render:epNN` script. Import Lumi and Bobo from `src/story/characters.tsx` (never redraw them), and reuse `src/story/scenery.tsx`, `src/ep02/props.tsx`, `src/ep03/props.tsx`.
- Voices from Ep 2 on: Kokoro (free, offline; setup in `scripts/ep02_voices.py`). Lumi `af_bella` pitched 1.14, Bobo `am_puck` pitched 1.18, narrator `af_heart`, butterfly `af_sky` pitched 1.25. The venv and model now live permanently in `lumi-studio/engine/` (see [[lumi-studio-app]]).
- Characters have no knee-bend pose: Ep 3 fakes kneeling by lowering the character behind a foreground flower bed.
- The user asked for 1080x1920, 30 fps, 40-45 s, no logo intro, strong hook in the first second, and a curiosity ending with "To Be Continued... ✨" and "Little Moon Story World 🌙". They expect a real render plus validation before reporting done.
- The bundled ffmpeg (`node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe`) lacks the rawvideo muxer and the fps/tile filters; extract PNG frames instead.
